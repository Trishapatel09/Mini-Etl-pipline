# Mini ETL Pipeline

## 📌 Project Overview

This project is a Mini ETL Pipeline built using Python. It extracts weather data from an API, transforms the raw data into a clean format, loads it into a SQLite database, and generates reports for analysis.

---

## 🎯 Objectives

- Learn ETL (Extract, Transform, Load)
- Understand Data Engineering fundamentals
- Practice Python with real-world data
- Learn Git & GitHub workflow
- Build an interview-ready project
